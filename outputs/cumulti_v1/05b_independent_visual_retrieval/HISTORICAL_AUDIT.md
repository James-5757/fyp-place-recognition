# Read-only historical audit, before Stage5B execution

No validated independent full-4180 Robot1-to-Robot3 RGB experiment was found in the accessible repository, historical documentation, server outputs and retained embedding caches. This applies individually to Single RGB, RGB5 Mean and Cross-Max, including the exact same-view482 experiment. The inspected methods are candidate-pool rerankers. No historical complete visual ranking/first-positive-rank artifacts for this all-database protocol were found. A cache containing4180 descriptors does not establish that4180 candidates were ranked per query.

Stage5 explicitly says frozen SC Top20 and `rerank_top20` only accepts the selected candidate rows. Stage7.5 imports that reconstruction and passes `demb[candidates]`, not the complete database, into the scorer. Its committed same-view CSV records482 queries but remains a Top20 visual result. `visual-only` describes the final scoring function inside this inherited pool. KITTI scripts called `full_rgb`/`full_temporal` read the SC-generated candidate CSV, restrict rank<=top_k(default5), and optionally fuse scores. They are full-query-cohort reranking runs, not unrestricted retrieval. Their current source candidate CSV has158 valid queries and10 saved candidates per valid query before the default top5 restriction.

Direct source ranges and artifact paths are in historical_audit.csv. Historical Stage5 raw CSV outputs are not retained in the current checkout/server snapshot; corrected committed documentation is historical evidence, and Stage7.5 CSVs and Stage4 per-query/positive-pair CSVs are retained direct evidence. Stage5B will independently reproduce historical pooled metrics as a cache/protocol cross-check, while preserving all old files.

The accessible server retains only Stage5 R1/R3 and Stage7 R2 OpenCLIP embedding caches. A bounded find over processed_v1, current scratch and output trees found no retained full RGB ranking matrices. Existing Stage24 RGB-D appearance candidate/epoch-registration studies use a different camera-frame database/protocol and do not answer this4180-frame benchmark question. This negative audit is scoped to accessible evidence; it cannot establish the absence of deleted or inaccessible historical experiments.

Decision: proceed with isolated Stage5B. No old source, cache or scientific output was edited during the audit. Ground truth will be evaluation-only, after independent complete rankings are persisted. The SC full matrix must be reconstructed using frozen scoring because only its canonical per-query first-positive ranks and rank1 IDs are retained; these will be checked exactly.

Stage6 also computes visual scores only for `top20[i]` and moves a selected pool member to Rank1. Stage7 held-out transfer uses a different query robot and the inherited Top20 scoring; neither supplies the requested independent R1-to-R3 benchmark.
